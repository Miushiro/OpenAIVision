
# OpenAI Chat integration with OCR File Uploading

  

This template provides a minimal setup to get any LLM to work directly with image OCR uploaded from a source

  
**__Tech Stack__**
>* Server: ElysiaJS with Bun
>* Logging: Logixlysia
>* Frontend: React with Vite
>* Theming: Ant Design
>* CSS: TailwindCSS
>* Routing: React Router V5
>* Type handling: Zod V4
